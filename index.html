设计词架 · 隐私政策

适用范围

本政策适用于“设计词架 · 设计提示词助手”Chrome 扩展的普通用户版。更新日期：2026年10月9日。

本地保存的信息

扩展处理并在当前 Chrome 配置文件的 chrome.storage.local 中保存你输入的个人提示词、收藏、项目背景、填写内容、编辑草稿、最近使用记录、精选内容缓存与配置。最近使用记录用于显示最近使用的提示词。上述内容不上传给开发者，不使用云端同步。开发者无法通过扩展读取这些本地内容。

不采集的信息

扩展无需注册账号，不接入 AI 服务，不要求填写姓名、地址、电话、身份信息或付款信息，不读取浏览历史、网页内容、账号或设计截图，不包含广告、分析 SDK 或遥测。不上传使用记录，不进行行为分析。用户自愿输入到提示词中的信息作为用户内容仅在本地处理。

复制、分享与备份

仅在你点击复制或分享时，扩展将相应内容写入系统剪贴板；分享功能生成供你自行发送的文字，不自动发布给他人。导出备份会生成本地文件。你将内容粘贴给 AI 工具或发送给他人的行为由你决定，目标服务适用其自身隐私政策。

可选在线内容更新

你配置 HTTPS 内容源并授权后，只有主动点击更新才发起读取 JSON 内容包的 GET 请求。不发送个人提示词、草稿或使用记录，不携带账号 Cookie 或认证信息。内容托管方可能接收 IP 地址、请求时间等常规连接信息，其处理受该服务的隐私政策约束。内容签名用于验证来源，不用于识别用户。

Skill 来源与源码下载

点击来源链接会打开第三方网站。主动下载 Skill 时，首次申请 codeload.github.com 域名访问权限，向 GitHub 发出 GET 请求并保存源码 ZIP。不附带账号 Cookie、个人提示词或安装记录。GitHub 可能接收 IP 地址等常规网络信息。本扩展不自动安装或执行 Skill；复制安装命令只写入剪贴板。推荐中的安装量为维护者整理的公开快照，不通过用户端统计安装行为。

权限用途

storage 用于上述本地保存；sidePanel 用于提供浏览器侧边栏操作界面。可选 HTTPS 主机权限仅在配置内容源或主动下载时申请相应域名，不用于读取你访问的网页。

保留、删除与控制

本地信息持续保留以支持复用，直到你删除相关内容或卸载扩展。可删除个人提示词；恢复原始模板可清除该条填写内容与编辑草稿。清空在线更新地址可关闭内容源并撤销相应权限；网站授权可在 Chrome 扩展设置中管理。卸载扩展可删除扩展本地数据；已导出的文件和剪贴板副本需由你自行删除。

数据使用与保护

个人内容只用于提供提示词编辑、收藏、备份及最近使用等明确功能。开发者不出售用户数据，不将其用于广告、与单一用途无关的目的或信用评估。扩展对外请求使用 HTTPS，不加载或执行远程 JavaScript。对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。
